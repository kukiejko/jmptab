Import CSV, tab-delimited TXT, XLSX, row-based XML, or Excel 2003 SpreadsheetML XML. XML uses the first tabular dataset (or the first worksheet in SpreadsheetML). Edit the sample worksheet to start without a file. Use the plus button beside the worksheet tabs to add a sheet, the arrow buttons to switch sheets, and the bottom bar to scroll wide sheets horizontally. Save session keeps all worksheets, formulas, fitted DOE models, and result history. Choose an analysis and a numeric response column, then run it. Results are snapshots; run again after editing.

Resize panes by dragging the bar beside Navigator or above Worksheet. Drag a worksheet column's right-edge grip in the C1/C2 header to change its width. Double-click a column grip to fit the widest text in that column; double-click a pane divider to reset it. Arrow keys also work when a grip has focus. Resize dialogs from the lower-right corner. Click a C1/C2 column header to select a whole column, Shift-click to select a range, or Ctrl-click to add or remove columns. Ctrl+C copies selected columns with their names; select a destination header and press Ctrl+V to replace whole columns. Pasting into a cell continues to fill cells from that position.

Statistical methods

Descriptive statistics use the sample standard deviation (n − 1) and linearly interpolated quantiles. Regression is ordinary least squares with an intercept; missing pairs are excluded. One-way ANOVA uses an F test and Tukey comparisons for grouped numeric responses.

For 1-Sample t, enter independent continuous observations or sample size, mean, and sample standard deviation. For example, values 1, 2, 3, 4, 5 have mean 3 and a 95% two-sided confidence interval of about 1.037 to 4.963. The t statistic divides the difference from the hypothesized mean by the standard error, s/√n. The p-value measures how extreme the result is under that hypothesis. Check the sampling and distribution assumptions before interpreting a small sample.

Single exponential smoothing uses the first observation or the mean of the first k observations as its starting value. Each fitted value uses the prior smoothed value; the final smoothed value forecasts the next period.

Moving averages use the preceding observations to fit each point. The next-period forecast is the mean of the latest span. Missing or nonnumeric values must be resolved to preserve time order.

Xbar-S charts plot subgroup means and standard deviations. Xbar charts group consecutive observations and plot each subgroup mean. With no known standard deviation, the estimate is the average subgroup standard deviation divided by c4. A target mean and known standard deviation may set the limits.

P charts plot defective counts divided by items per subgroup. Limits use the center proportion ± 3 standard errors, clipped to 0 and 1. An optional target proportion sets the center line.

Individuals charts use mean ± 3σ, where σ = average consecutive moving range / 1.128. Only points outside these limits are flagged. Observation order is preserved; missing values must be resolved first.

Capability uses this within-process σ for Cp/Cpk and sample standard deviation for Pp/Ppk. Normality, process stability, and representative sampling must be assessed separately; no normality test is included.
